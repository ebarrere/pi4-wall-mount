# Raspberry Pi hanger

Use this to mount a Raspberry Pi 4 horizontally on the wall, assuming the Pi is mounted in [this case](https://www.printables.com/model/1240756-raspberry-pi-4-case-updated/files).

The mounting holes are sized and tapered for wood screws, but positioned to accomodate [Multiboard](https://thangs.com/designer/Keep%2520Making/3d-model/9x9%2520Multiboard%2520Core%2520Tile-977730).
